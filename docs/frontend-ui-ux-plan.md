# 현대백화점 AI 재고 수익 최적화 플랫폼 UI/UX 설계 및 마스터 기획서

## 1. 프로젝트 개요 및 디자인 읽기 (Design Read)

- **제품 정의**: 현대백화점 B2B 재고 의사결정 및 수익 최적화 운영 시스템
- **주 사용 대상**: 더현대 서울 재고 담당자 (일반 승인·실행) & 본사 예외 조정 담당자 (보조)
- **핵심 목표**: 단순 할인/소진 중심이 아닌 **증분 기여현금이익(Incremental Cash Margin) 최대화** 및 **악성재고 처리 기한 준수**
- **디자인 방향성 (Anti-slop / Taste & MengTo Style)**:
  - **Reading as**: 현대백화점 프라이빗 럭셔리 & 모던 오퍼레이션 타워 (Modern B2B Executive Dashboard).
  - **Tone & Palette**: Slate/Zinc 기반의 정갈한 모노톤 + 현대백화점 대표 컬러인 **딥 파인 그린 (`#0F4C3A`)** 중심의 고대비 억제 액센트.
  - **Banned Elements**: AI 퍼플/핑크 그라디언트, 네온 방출 효과, 카드 안의 카드 중첩, 무분별한 이모지 사용, 장식용 둥근 태그 남발.
  - **UI Density & Typography**: `VISUAL_DENSITY: 5` (데이터 밀도 높음, 여백과 수직 리듬 준수), `Geist Sans` + `JetBrains Mono` (숫자/금액 가시성 극대화).

## 2. 레퍼런스 상세 분석 (Mobbin & Pinterest Charts)

### 2.1 Mobbin Dashboard & Charts 패턴 분석
1. **Metric Strip & Metric Card**:
   - 화면 상단에 3~4개의 핵심 KPI(총 악성재고 금액, 예상 기여이익, 폐기 위험 회피금액, 시뮬레이션 승인율)를 수평 밴드로 배치.
   - 숫자 변경 시 미세한 애니메이션 및 증감 추이(Positive/Negative)는 명확한 컬러 칩으로 구분.
2. **Horizontal Stacked Bar**:
   - 복잡한 파이 차트 대신 카테고리별/점포별 재고 상태(안전/주의/위험/악성임박/악성)를 한눈에 비교할 수 있는 수평 스태킹 바 활용.
3. **Restrained Filter Bar**:
   - 데이터 테이블 상단에 더현대 서울 층/매장(2F·3F·B1·1F), 매입 유형(직매입/특약매입/임대), 카테고리, 위험도 등급 필터를 고정 영역으로 배치.

### 2.2 Pinterest 그래프 UI 시뮬레이션 패턴 분석
1. **Dual-Axis / Toggle Comparison Graph**:
   - 전략별 예상 판매량(수량 축)과 예상 기여이익(금액 축)을 한 그래프 안에서 입체적으로 비교.
   - 할인율 증가에 따른 '매출 증가'와 '순마진 감소'가 교차하는 **최적 마진 지점(Optimal Profit Point)**을 시각적으로 강조.
2. **Scenario Band & Step Flow**:
   - 2~3개 시나리오(최대 순마진, 최대 소진속도, 최고 매출)를 Overlay 선으로 비교.
   - 도달 실패 시 2차/3차 사후 대처 플랜(추가 할인, 팝업스토어 이관, 벤더 회수)을 단계별 트리 형태로 표시.

## 3. 디자인 시스템 및 기술 스택 세팅

### 3.1 프론트엔드 기술 스택
- **Framework**: Next.js (App Router, Server Components 기본 + Client State 최소화)
- **Styling**: Tailwind CSS v4, shadcn/ui (Customized Theme)
- **Icons**: Lucide React / Phosphor Icons (동일 패밀리 strokeWidth 1.5 통일)
- **Data Table**: TanStack Table (v8) - 정렬, 필터, 멀티 셀렉션, 스티키 헤더
- **Data Visualization**: Recharts / Visx (지연 로딩 처리, 커스텀 툴팁, 접근성 서포트)
- **State Management**: React State & TanStack Query (추후 서버 연동 대비)

### 3.2 컬러 및 디자인 토큰
- **Primary Accent**: Deep Fine Green (`bg-[#0F4C3A]`, `text-[#0F4C3A]`)
- **Background**: Neutral Paper / Soft Slate (`bg-zinc-50` / `dark:bg-zinc-950`)
- **Surface**: Pure White / Dark Slate (`bg-white` / `dark:bg-zinc-900`, `border-zinc-200`)
- **Status Badges**:
  - **안전 (Safe)**: Emerald-50 / Emerald-700 (`#047857`)
  - **주의 (Caution)**: Amber-50 / Amber-700 (`#B45309`)
  - **위험 (Warning)**: Orange-50 / Orange-700 (`#C2410C`)
  - **악성임박 (Critical Near)**: Rose-50 / Rose-700 (`#BE123C`)
  - **악성 (Dead Stock)**: Red-100 / Red-800 (`#991B1B`)

## 5. 페이지별 상세 UI/UX 구현 명세

### 5.1 대시보드 (`/dashboard`)
- **상단 요약 메트릭**:
  - 총 관리 재고 금액 & 직매입 비중
  - 위험/악성 재고 총액 및 전체 재고 대비 비율
  - AI 전략 적용 시 예상 회피 폐기비용 및 증분 기여이익
- **메인 영역**:
  - **층/매장별 재고 위험도 분포 현황**: 더현대 서울 2F·3F·B1·1F Stacked Bar
  - **AI 추천 우선 처리 재고 TOP 5**: 긴급 처리가 필요한 직매입 악성재고 퀵 카드 및 바로가기
  - **최근 수립된 AI 전략 이행률 & 효과 차트**: 승인된 전략의 실제 판매 소진율 추이

### 5.2 전체 재고 조회 (`/inventory/all`)
- **테이블 구조 (TanStack Table)**:
  - 컬럼: [선택, 상품코드, 상품명, 점포명, 매입구분(직매입/특약/임대), 현재고, 원가, 판매가, 보관일수, 유통기한/시즌종료일, AI 재고상태 태그, 판단 사유]
- **AI 재고 상태 태그 & 추론 엔진 요약**:
  - 스케줄러에 의해 분류된 태그(안전, 주의, 위험, 악성임박, 악성)와 클릭 시 레이어 팝업으로 상세 사유 표시 (예: "과거 30일 판매 속도 대비 보유 재고 소진에 120일 소요 예상, 시즌 종료 D-15")
- **필터 & 검색**:
  - 점포별, 카테고리별, 매입구분별, AI 상태 등급별 다중 선택 필터링

### 5.3 위험(악성) 재고 조회 (`/inventory/risk`)
- **특화 기능**:
  - 위험, 악성임박, 악성 상태의 재고만 모아서 표시.
  - **체크박스 다중 선택 기능**: 개별 또는 여러 상품을 선택하여 일괄 AI 전략 수립 요청.
- **번들(Bundle) 구성 옵션 UI**:
  - **[번들 구성 생성 포함]** 체크박스 제공.
  - **직접 지정 모달**: 사용자가 함께 묶을 연관 카테고리 상품을 모달에서 직접 검색 및 지정.
  - **AI 자동 지정**: 지정하지 않을 경우, AI가 사용 목적 연관성 및 합산 마진율을 계산하여 적합한 보완 상품을 자동으로 묶음.
- **하단 픽스드 바 (Drawer Bar)**:
  - 선택한 상품 개수 및 총 재고 금액 표시 + `[개별/번들 AI 전략 생성 시작]` 버튼.

### 5.4 AI 전략 수립 및 실행 (`/strategy/generate`)
- **상태 진행 시각화**:
  - 전략 생성 중 (Progress Bar & AI 분석 단계 표시: 데이터 수집 → 순수익 시뮬레이션 → 번들 매칭 → 전략 확정)
  - 생성 완료 / 실패 알림 처리.

### 5.5 전략 기록 및 상세 비교 (`/strategy/history`, `/strategy/[id]`, `/strategy/[id]/simulate`)
- **전략 목록 (`/strategy/history`)**:
  - 전략 ID, 대상 상품/번들명, 생성일시, 상태(대기/승인/실행중/완료), 예상 증분이익 표시.
- **전략 상세 비교 및 시뮬레이션 (`/strategy/[id]`)**:
  - **상단 AI 추천 시나리오 카드 카탈로그**:
    1. **시나리오 A (최대 순마진 우선)**: 15% 할인 + 타겟 쿠폰 → 순이익 극대화
    2. **시나리오 B (최단기간 소진 우선)**: 30% 타임세일 → 악성재고 신속 소진
    3. **시나리오 C (최대 매출 우선)**: 전용 쿠폰 + 오프라인 행사장 전시 → 매출 규모 확보
  - 카드 본문 클릭은 상세 시뮬레이션 팝업을 열며, 체크박스는 비교함에 제한 없이 전략을 추가한다.
  - **시뮬레이션 그래프 (Dual-Axis Chart)**는 시뮬레이션 화면에서만 표시한다.
    - X축: 할인율
    - Y축 L: 예상 증분 기여현금이익 (비용·폐기 회피 비용 반영)
    - Y축 R: 예상 판매량
    - AI 추천 원본과 사용자 조정 곡선을 함께 비교한다.
  - **사후 대처 (Fallback Action Plan) 스티어링**:
    - 목표 소진율 미달 시 90–100%, 70–89%, 50–69%, 30–49%, 0–29% 구간별 대응(추가 혜택, 번들 전환, 회수·기부·폐기 비교)을 사전 설정 및 시각화.

### 5.6 재고 건강도 통계 (`/analytics`)
- **분석 보고서**:
  - 더현대 서울 층·카테고리별 재고 회전율 추이
  - 할인율별 판매 반응도 (과거 데이터 기반 할인 반응 곡선)
  - 직매입 재고 폐기 손실 절감 리포트

## 6. 구현 전 확인 및 검증 기준 (Pre-flight Check Rules)

1. **코드 작성 범위**: 전략 카탈로그·시뮬레이션 워크벤치 P0/P1 UI는 더미 데이터로 구현되었으며, 실제 데이터/API 연동은 후속 단계로 남긴다.
2. **AI-Slop 검증 규칙 적용**:
   - 무분별한 보라색/그라디언트 억제 및 현대백화점 그린 액센트 적용 확인.
   - 단일 페이지 단일 accent color 고정.
   - 데이터 테이블 및 차트의 반응형 및 모바일/데스크톱 시각화 가시성 보장.

## 7. 2026-07-24 대화 반영 기록: 전략 카탈로그·세밀 시뮬레이션 분리

대안 시나리오가 7개 이상으로 늘어날 때 하나의 화면에 모든 차트를 겹쳐 보여주면 판단에 필요한 정보보다 시각적 과밀이 커집니다. 이에 전략 선택 화면과 조건 조정 화면의 책임을 분리합니다.

### 7.1 전략 카드 목록과 시뮬레이션 화면의 역할 분리

- `/strategy/[id]`는 전략 카드·비교 선택·간단한 KPI만 제공합니다.
- 카드 본문 클릭은 해당 전략을 시뮬레이션 화면으로 엽니다.
- 체크박스는 카드 이동과 독립적으로 비교함에 전략을 추가·제외합니다.
- 비교 전략은 개수 제한 없이 선택할 수 있습니다.
- `/strategy/[id]/simulate?options=...`는 비교함에 담긴 전략 전체의 상세 조정과 비교를 담당합니다.
- 시뮬레이션 화면에서만 대형 차트, 비용 브레이크다운, AI 원본과 사용자 조정안 비교, 사후 대처 트리를 보여줍니다.

### 7.2 사용자가 조정할 수 있는 P0/P1 조건

P0 화면 조정값은 다음과 같습니다.

- 상품 할인율
- 쿠폰 부담률
- H.Point 적립률
- 무료배송 여부와 건당 배송비 부담
- 프로모션 기간
- 적용 수량
- 번들 판매 여부와 번들 추가 할인율

P1 확장값은 다음과 같습니다.

- 광고·노출 예산
- 채널별 판매 비중
- 반품률 가정
- 포장·피킹·번들 조립비
- 보관비와 폐기 처리비 가정

원가, 현재고, 유통기한, 소유권, 최대 할인 한도, 안전·물류 제약은 사용자가 임의로 조정하지 않는 읽기 전용 가드레일입니다.

### 7.3 시뮬레이션 결과 기준

조건을 변경하면 다음 값이 함께 재계산됩니다.

- 예상 판매량·매출·소진기간·잔여재고
- 할인·쿠폰·포인트·배송·플랫폼·운영·반품·보관 비용
- 회피되는 폐기 비용
- 기준선 대비 증분 기여현금이익
- 예측 신뢰도와 하방 경고
- 판매 달성률 90–100%, 70–89%, 50–69%, 30–49%, 0–29% 구간별 사후 대처

할인·쿠폰·포인트·무료배송은 단순 합산하지 않고 더미 판매 반응 곡선과 조합 보정 계수로 계산합니다. 사용자 조정안은 AI 추천 원본과 별도 값으로 표시하며, 승인 전에는 실제 가격·쿠폰·재고를 변경하지 않습니다.

### 7.4 범위 기준 보정

현재 MVP의 관제 범위는 현대백화점 **더현대 서울 2F·3F·B1·1F 직매입 재고**입니다. 다른 점포·다른 계열사·점포 간 재고 이동은 비교 검토용 P2 확장 범위로 남기며, 일반 전략의 승인 주체는 본사가 아니라 더현대 서울 재고 담당자입니다.

### 7.5 누락 방지용 P0 운영 기준

앞선 기능 검토에서 확인한 누락 항목도 이후 화면과 데이터 계약의 기준으로 확정합니다.

- 데이터 신선도·완전성·판매 이력 기준 기간·예측 신뢰도를 결과마다 표시한다.
- 현재 판매 유지, 즉시 폐기, 보유 후 폐기, 벤더 회수, 기부를 기준선 대안으로 함께 비교한다.
- 증분 기여현금이익은 할인·쿠폰·포인트·수수료·배송·피킹·포장·번들 조립·반품·보관·폐기·정상 판매 잠식 비용을 반영한다.
- 동일 상품·동일 브랜드·동일 카테고리·키워드·용도·가격대·시즌의 유사 상품 가중치와 표본 부족 경고를 표시한다.
- 위험 탐지 → 전략 생성 → 담당자 검토 → 승인 → 실행 대기 → 실행 중 → 결과 수집 → 완료/실패 상태를 기록한다.
- 예상 판매량·소진일·기여이익과 실제 결과를 비교할 수 있도록 실행 후 결과 회수 영역을 둔다.
- 일반 전략은 더현대 서울 담당자가 승인하며, 본사는 그룹 비용·공동 프로모션·예외 위험이 발생할 때만 개입한다.
