# 현대백화점그룹 3개 계열사 재고 처리 의사결정 정책

## 정책 목적

모든 재고 처리 판단은 **현대웰니스, 현대리바트, 현대그린푸드**의 계열사·점포·부서 단위로 수행합니다. 통합 화면에서 비교하더라도 상품 정책, 처리기한, 보관 조건, 권한은 계열사별로 적용합니다.

이 서비스는 주문·결제·배송·상품 등록을 실행하지 않습니다. 전략을 계산·승인·전달하고, 실제 판매·정산 결과는 외부 시스템에서 회수합니다.

담당 MD는 소속 계열사의 기준선보다 큰 위험조정 증분 기여현금이익을 만드는 전략을 선택합니다. 검색·SNS·판매 트렌드는 수요예측의 보조 입력으로 사용하며, 계열사 간 비교와 재고 이동은 1차 검증 이후의 후순위(P2) 기능입니다.

## 주요 용어

- **계열사 기준선**: 해당 계열사에서 프로모션을 하지 않아도 실행 가능한 대안 중 가장 유리한 결과
- **기여현금이익**: 전략 때문에 실제로 변하는 현금 유입·유출과 회피비용
- **증분이익**: 전략 결과에서 해당 계열사 기준선 결과를 뺀 값
- **매몰원가**: 이미 발생해 전략 선택으로 변하지 않는 취득원가·장부가
- **회피비용**: 전략으로 줄어드는 보관비·폐기비·회수비

## 최종 최적화 목표

```text
max M_inc(s)
= 추가 매출액 + 피한 폐기·보관비
− 정상판매 잠식손실 − 물류·재포장비
− 브랜드 훼손비용 − 반품·CS 비용 − AI 처리원가
```

처리기한과 식품안전·소유권·정책·데이터 품질은 비용 항목이 아니라 하드 차단 제약조건입니다. 제약조건을 위반한 대안은 이익이 커 보여도 후보에서 제외합니다.

## 비용 분류

### 매출·판매 조건

- 할인, 쿠폰, 포인트, 무료배송 부담
- 결제·플랫폼·채널 수수료
- 환불, 가격보상, 정산 지연
- 판매 시점과 현금 회수 시점 차이

### 처리·물류

- 피킹, 포장, 번들 조립, 라벨, 재포장, 품질검수
- 배송, 역물류, 파손, 분실
- 냉장·냉동·특수 보관 비용
- 추가 고객지원·운영 인력

### 반품·품질

- 환불액과 반품 역물류
- 재판매 불가·등급 하락 손실
- 고객 보상과 품질검수
- 식품 검사·리콜·안전 기준 위반 위험

### 보관·공간

- 일자·상품·부피·온도별 보관비
- 실제 공간이 비워질 때의 공간 대체가치
- 시즌 경과와 품질 저하
- 현금이 묶이는 기간

### 잔여·처분

- 실행 후 잔여재고의 만료·폐기 가능성
- 폐기 운송·처리·증빙 비용
- 기부·벤더 회수·잔존가치
- 회계상 손상차손과 실제 현금비용의 구분

### 전략적 영향

- 정상 판매 잠식과 채널 간 충돌
- 향후 가격 기대 하락과 브랜드 훼손
- 프로모션·보관·배송·설치 비용의 기회비용
- 점포 내부 비용 배부·정산 차이

## 중복 계산 방지

- 판매이익에 할인·수수료·배송·반품이 이미 반영됐는지 확인합니다.
- 환불과 반품 역물류를 각각 계산하되 동일 비용을 중복 적용하지 않습니다.
- 전략으로 변하지 않는 취득원가·고정 본사비·배부 임차료는 증분비용에서 분리합니다.
- 폐기비용과 회계상 손상차손을 동일 항목으로 계산하지 않습니다.
- 쿠폰·포인트·번들 할인은 실제 적용 순서에 따라 한 번만 반영합니다.
- 판매·반품·파손·만료·잔여 상태는 서로 겹치지 않도록 정의합니다.

## P0/P1 처리 우선순위

1. 현재 계열사·점포·채널에서 정상 판매 유지 가능성 확인
2. 제한 할인·타임세일·타깃 프로모션 비교
3. 별도 판매 채널·채널 전환·기부·회수·폐기 비교
4. 예상 판매량·잔여재고·보관·폐기·반품·배송·설치·AI 원가 계산
5. 책임 MD 승인
6. 실행 결과 회수와 예측 오차 기록

계열사 간 또는 점포 간 이동은 위 흐름이 검증된 뒤 P2로 추가합니다. P2에서는 보내는 조직과 받는 조직의 이익을 분리 계산하고 이동비·수신 용량·판매속도·권한을 모두 확인합니다.

## 하드 차단 조건

- 식품안전·소비기한·법규·리콜 조건 위반
- 재고 소유권 또는 처분 권한 미확인
- 브랜드별 최대 할인율 또는 채널 정책 위반
- 계열사·점포·채널의 처리·배송·보관 용량 초과
- 원가·판매·기한·비용 데이터의 신뢰도 미달
- 승인되지 않은 가격·수량·재고 변경 요청

## 일반 승인과 예외 검토

해당 계열사의 담당 MD는 자사 계열사·점포 정책 안에서 일반 전략을 승인합니다. 승인 전에는 시뮬레이션 조건을 조정할 수 있으며, 승인 후 변경은 재승인 대상입니다.

그룹 및 계열사 재고전략 담당자는 다음 경우에만 예외를 검토합니다.

- 대규모 위험재고로 손실 영향이 큰 경우
- 추가 예산·브랜드·법규·안전 위험이 있는 경우
- 계열사·점포 간 이동 또는 공동 비용 분담이 필요한 경우(P2)
- 일반 정책의 예외 할인·채널·처분이 필요한 경우

## 전략 시나리오

AI는 목적별 시나리오를 최대 3개까지 제시할 수 있습니다.

- **순마진 극대화**: 할인폭을 줄이고 증분 기여현금이익을 보호
- **빠른 소진**: 처리기한 안에 잔여재고를 최소화
- **최대 매출**: 외형 매출과 판매수량을 확대

세 시나리오는 비교 관점이며, 최종 승인 순위는 하드 차단을 통과한 대안의 `M_inc`로 결정합니다.

## 불확실성 정책

할인 반응이나 폐기 확률을 충분히 추정할 수 없으면 유리하다고 가정하지 않습니다. 보수적·기본·낙관 시나리오를 구분하고 다음을 함께 제시합니다.

- 신뢰도와 근거 데이터 기간·표본 수준
- 예상 증분이익과 하방 결과
- 손실 발생 가능성
- 처리기한 이후 잔여재고와 폐기 가능성
- 결과를 바꾸는 핵심 변수와 손익분기 조건

## Teams 전달 원칙

Microsoft Teams는 승인된 전략 조건을 계열사별 매장·물류·운영 담당자에게 전달하는 알림 채널입니다. 실제 주문·배송·상품 등록은 외부 시스템에서 진행합니다.

- 대상 계열사·상품·상품코드·점포·채널
- 적용수량·할인율·기간
- 예상 판매량·증분이익·주의사항
- 상세 전략 링크

최종 승인과 조건 변경은 본 서비스에서 수행합니다. Teams 메시지는 승인 기록을 대체하지 않습니다.

## 예상 결과와 실제 결과

실행 종료 후 다음 값을 비교합니다.

- 예상 판매량과 실제 판매량
- 예상 마진·증분이익과 실제 값
- 예상 소진기간과 실제 소진기간
- 예상 잔여재고와 실제 잔여재고

차이가 발생하면 행사 노출 부족, 날씨, 인기 사이즈 품절, 경쟁 행사, 운영 문제 등의 원인을 코드화해 다음 모델 검증에 사용합니다.

## AI와 사람의 책임

AI는 계열사별 정책을 반영해 위험도·비용·판매량·전략 후보·설명 문장을 계산합니다. 가격·할인·수량·재고 이동·폐기 실행의 최종 결정은 권한 있는 해당 계열사 담당 MD가 내립니다.
