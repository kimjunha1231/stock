# 멘토 의견과 확정 결정사항

## 출발점

기존 기획은 현대백화점그룹 계열사의 상품·재고·배송 정보를 연결하고, AI가 계열사 간 묶음 상품과 프로모션을 추천하는 통합 커머스 서비스였습니다. 통합 장바구니, Mock 결제, 계열사별 주문 분리까지 포함해 소비자 구매 경험을 구현하려는 방향이었습니다.

## 멘토의 핵심 평가

멘토는 재고 비용과 손실을 줄이려는 문제 정의, AI를 활용한 수요예측·번들·할인 전략, 추천과 시뮬레이션을 시각화할 수 있다는 점을 강점으로 보았습니다.

동시에 범위가 지나치게 넓어 AI 의사결정 가치보다 쇼핑몰 구현에 시간이 쏠릴 위험이 있다고 판단했습니다. 또한 사용자 역할과 교차판매 기준이 불명확하다는 점을 보완사항으로 제시했습니다.

## 1차 개선 결정

### 쇼핑몰에서 의사결정 지원으로 전환

제품의 중심을 소비자 구매가 아니라 재고 처리 판단으로 바꿉니다. 장바구니, 결제, 소비자 주문, 계열사 주문 분리는 핵심 범위에서 제외합니다.

### 계열사 담당자를 주 사용자로 전환

계열사가 자사 재고·비용·물류·손익을 가장 잘 알고 실제 실행 결과에 책임집니다. 따라서 일반적인 전략의 판단과 승인은 계열사 담당자가 맡습니다.

### 본사는 예외 거버넌스 사용자로 전환

본사는 계열사의 일반 전략을 일괄 승인하지 않습니다. 전체 위험 규모를 보고 공통 정책을 관리하며, 계열사 간 공동 프로모션, 추가 예산, 그룹 위험, 비용·책임 충돌 같은 예외에만 개입합니다.

### 계열사별 최적화로 전환

모든 계열사를 하나의 비용 함수나 하나의 AI 모델로 묶지 않습니다. 각 계열사는 자체 비용·물류·처리기한·고객 맥락에 맞는 판단 기준을 사용하고, 본사는 공통 지표로 결과를 비교합니다.

## 하이브리드 의사결정 방식

계열사별 규칙 기반 위험도 계산, 과거 데이터 기반 수요·할인 반응 추정, AI의 설명·전략 추천을 결합합니다. AI가 근거 없이 가격과 재고를 직접 결정하지 않도록 역할을 분리합니다.

## 계열사별 판단 원칙

1. 자사 배송·보관·안전·처리 조건 확인
2. 자사 기준선과 처리 대안 비교
3. 자사 비용·기여현금이익·잔여재고 확인
4. 계열사 담당자가 일반 전략 승인
5. 실행 결과를 자사 기준으로 기록

## 본사 개입 원칙

본사는 다음 경우에만 개입합니다.

- 계열사 간 공동 프로모션
- 공동 비용 분담 또는 그룹 예산 지원
- 그룹 전체에 큰 영향을 주는 위험재고
- 브랜드·법규·안전과 관련된 예외
- 계열사 간 합의가 필요한 사안
- 다른 계열사가 참고할 우수 사례의 표준화와 공유

본사는 승인된 우수 사례의 조건과 결과를 공유하되, 계열사의 민감한 원천 비용이나 운영 데이터를 기본적으로 공개하지 않습니다.

## 비용 검토로 확정된 원칙

- 이미 발생한 취득원가와 장부가는 전략 비교에서 매몰비용으로 분리합니다.
- 할인·수수료·물류·보관·반품·폐기·잠식·정산 비용을 계열사 기준으로 비교합니다.
- 판매·반품·파손·만료·잔여 상태의 비용을 중복 계산하지 않습니다.
- 각 계열사의 최선의 비프로모션 대안을 기준선으로 사용합니다.
- 마진율은 단독 목표가 아니라 기여이익 가드레일과 설명지표로 사용합니다.
- 음의 기여이익 전략은 폐기 대안보다 유리한 경우에만 계열사 승인제 예외로 허용합니다.
- 안전·유통기한·소유권·용량·데이터 품질 위반은 비용보다 우선하는 하드 차단입니다.
- 기대값만 제시하지 않고 하방 시나리오와 손실 가능성을 함께 보여줍니다.

## 공동 프로모션 원칙

계열사 간 상품을 물리적으로 묶는 것은 기본 기능이 아닙니다. 양쪽 계열사가 동의하고, 배송·보관·비용 분담·정산 조건이 확인된 경우에만 예외적으로 검토합니다.

조건이 맞지 않으면 공동 배송 대신 포인트, 쿠폰, 별도 채널 프로모션 같은 소프트 연계를 우선합니다.

## 1차 검증 범위

계산과 실행 검증은 한 계열사에 집중합니다. 특정 계열사를 문서에서 미리 고정하지 않고, 실제 데이터 품질과 운영·물류 조건을 비교해 Anchor 계열사를 선정합니다.

다른 계열사는 처음부터 동일한 수준으로 구현하지 않습니다. 본사 비교 화면과 확장 가능성을 고려하되, 각 계열사별 최적화는 충분한 데이터와 운영 검증이 확보된 뒤 확장합니다.

## 추가 확정사항 (직매입 필수 & 점포 간 이동 선택)

- **직매입 재고 필수화**: 백화점/계열사가 소유권, 손익, 처분권을 100% 보유한 직매입 재고(예: 식품관 등)를 1차 핵심 서비스의 필수 대상 범위로 고정합니다. 특약매입 등 입점업체 책임 재고는 승인 대상에서 제외하거나 판촉 제안으로 분리합니다.
- **점포 간 재고 이동 선택화**: 핵심 1차 처리 전략(할인, 타임세일, 아울렛 이관, 기부, 폐기)을 먼저 정밀하게 구축한 후, 점포 간 이관 및 수송비 반영 전략은 선택적/후순위 기능(P2)으로 배치합니다.

## 계속 지켜야 할 경계

- 계열사의 일반 운영 책임을 본사 승인 절차로 되돌리지 않습니다.
- 쇼핑몰 기능을 늘려 재고 의사결정 범위를 흐리지 않습니다.
- 가장 많이 팔리는 전략을 최적 전략으로 오해하지 않습니다.
- 고정된 최소마진율 하나로 폐기보다 유리한 처분 전략을 차단하지 않습니다.
- 계열사별 손익과 그룹 전체의 비교 지표를 섞지 않습니다.
- 본사는 통합 통제자가 아니라 예외 조정자와 우수 사례 공유자입니다.

## 최종 한 문장

> 이 서비스는 계열사가 자사 재고를 스스로 최적화하도록 돕고, 본사는 예외 상황을 조정하며 승인된 우수 사례를 그룹 전체에 공유하는 분산형 재고 의사결정 플랫폼입니다.
