# 멘토 의견과 최신 확정 결정사항

## 최신 기준

현재 프로젝트는 **현대웰니스, 현대리바트, 현대그린푸드**의 상품을 통합 관리하는 B2B 재고 의사결정 지원 서비스입니다.

- 3개 계열사의 상품·재고·판매·처리기한을 공통 화면에서 통합 조회
- 계열사별 상품 정책·보관 조건·판매 채널·권한은 분리 적용
- 소비자 쇼핑몰·장바구니·결제 제외
- 계열사별 대표 상품군을 1차 검증 기준으로 사용
- 계열사·점포 간 비교·재고 이동은 P2 후순위
- 가격·할인·재고 변경은 담당 MD 승인 전 실행 금지

## 핵심 제품 방향

제품의 중심은 소비자 구매가 아니라 계열사 통합 재고 처리 판단입니다. 담당 MD가 위험재고를 확인하고, AI가 비용·판매·기한·하방 위험을 계열사 정책에 맞춰 비교해 실행 가능한 전략을 제시합니다.

AI는 가격이나 재고를 직접 변경하지 않습니다. 담당 MD가 추천 이유와 시뮬레이션 결과를 확인한 뒤 승인합니다.

## 1차 사용자와 예외 사용자

### 일반 승인: 계열사별 점포·부서 책임 MD

1. 자기 점포의 재고와 위험 원인 확인
2. 소속 계열사 기준선과 처리 대안 비교
3. 할인·수량·기간·채널 조건 조정
4. 일반 전략 승인 또는 거절
5. 실행 결과와 예측 오차 기록

### 예외 검토: 그룹 및 계열사 재고전략 담당자

그룹 및 계열사 재고전략 담당자는 일반 전략을 대신 승인하지 않습니다. 대규모 손실, 예산, 브랜드·법규·안전 위험, 계열사 간 조정이 필요한 경우에만 개입합니다.

## 하이브리드 의사결정 방식

규칙 기반 위험도 계산, 과거 판매 데이터 기반 수요·할인 반응 추정, AI의 전략 설명을 결합합니다. 데이터 품질·소유권·안전·용량 하드 차단을 먼저 적용하고, 남은 대안만 손익으로 비교합니다.

## 1차 기능 범위

- 사용자 로그인·로그아웃·JWT 인증과 계열사·점포 권한
- 계열사 상품·카테고리·브랜드·옵션·SKU 공통 기준정보 관리
- 현재 재고·판매이력·재고변동이력 적재와 정기 갱신
- 통합 재고 대시보드와 필터·검색
- 상품·재고 위험 탐지
- 판매속도·보관일수·시즌/처리기한·사이즈 분포 분석
- 할인·타임세일·채널 전환·기부·회수·폐기 대안 비교
- 순마진·빠른 소진·최대 매출 시나리오 비교
- 수량·할인율·기간·쿠폰·포인트·배송비 시뮬레이션
- 책임 MD 승인과 상태 전이 감사
- 승인된 실행 내용의 Microsoft Teams 알림
- 예상값·실제값 비교와 목표 달성률·예측 오차·원인 기록

1차 실증은 각 계열사의 대표 상품군 1~2개를 우선 적용하고, 실제 데이터 품질과 계열사별 정책이 확인된 뒤 범위를 넓힙니다.

## P2 후순위 기능

- 계열사·점포 간 동일·유사 상품 비교
- 계열사·점포 간 재고 이동·수송비·수신 용량 계산
- 교차 계열사 번들상품 구성·재고 예약·매출 배분
- 예측 결과를 반영한 자동 재학습·모델 배포
- 1차 검증 이후의 신규 상품군·판매 채널 확장
- 계열사·채널 공동 프로모션

계열사·점포 간 이동은 할인·타임세일·채널 전환·기부·폐기 같은 1차 처리 전략을 먼저 검증한 후 추가합니다.

## 비용과 손익 원칙

- 취득원가·장부가는 매몰원가로 분리
- 할인·수수료·물류·보관·반품·폐기·정상판매 잠식 비용 반영
- 회피된 폐기·보관비는 이익에 더함
- AI 데이터·모델·LLM·사람 검토 원가를 별도로 기록
- 판매·반품·파손·만료·잔여 상태의 중복 계산 금지
- 기대값뿐 아니라 보수적·기본·낙관 시나리오와 하방 결과 표시

## 최종 목적함수

```text
max M_inc(s)
= 추가 매출액 + 피한 폐기·보관비
− 정상판매 잠식손실 − 물류·재포장비
− 브랜드 훼손비용 − 반품·CS 비용 − AI 처리원가
```

`Q_sale`은 위 목적함수에 넣을 예상 판매량을 계산하는 보조식입니다.

## 계속 지켜야 할 경계

- 3개 계열사 범위 밖의 조직을 제품 화면·권한·손익식에 포함하지 않음
- 계열사·점포 간 이동을 1차 성공조건으로 삼지 않음
- 본사의 일괄 승인 구조를 만들지 않음
- 판매량·매출만으로 최적 전략을 결정하지 않음
- 승인 전 실제 가격·수량·재고를 변경하지 않음
- Teams 메시지를 승인 기록으로 대체하지 않음

## 최종 한 문장

> 이 서비스는 현대웰니스·현대리바트·현대그린푸드의 담당 MD가 통합 재고와 트렌드 수요 현황을 바탕으로 자사 상품의 위험을 안전하고 수익성 있게 처리하도록 돕고, 계열사 간 이동은 검증 후 확장하는 사람 중심 재고 의사결정 플랫폼입니다.
