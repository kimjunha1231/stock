# 계열사 중심 AI 재고 최적화 서비스 개요

## 프로젝트 정의

현대백화점그룹의 각 계열사 재고 담당자가 자사 악성재고를 효과적으로 처리하도록 돕는 B2B 의사결정 지원 서비스입니다.

서비스는 계열사별 상품·비용·물류·운영 특성을 인정합니다. 각 계열사는 자사 재고를 스스로 판단하고 실행하며, 본사는 필요한 경우에만 그룹 관점의 조정과 지원을 제공합니다.

## 해결하려는 문제

현대백화점·현대홈쇼핑·현대리바트·현대그린푸드는 상품과 운영 방식이 서로 다릅니다. 장기보관 재고, 방송 후 잔여 재고, 창고 점유 재고, 유통기한 임박 재고를 동일한 기준으로 처리하면 실제 비용과 책임을 제대로 반영하기 어렵습니다.

각 계열사 담당자는 다음 판단을 내려야 합니다.

- 어떤 자사 재고를 먼저 처리해야 하는가
- 할인·폐기·반품·기부·대량판매 중 어떤 대안이 유리한가
- 처리기한 안에 재고를 얼마나 줄일 수 있는가
- 판매·보관·반품·폐기 비용을 포함해 실제로 이익이 남는가
- 어느 조건에서 본사나 다른 계열사의 협력이 필요한가

## 사용자

### 1차 사용자: 계열사 재고 최적화 담당자

자사 재고의 상태와 비용을 가장 잘 알고 실제 결과에 책임지는 사용자입니다.

- 위험재고 확인
- 자사 기준의 비용·물류 조건 검토
- 처리 전략 비교와 시뮬레이션
- 일반 전략 승인 및 실행 요청
- 실제 판매·잔여재고·비용 결과 회신

### 2차 사용자: 본사 재고전략·거버넌스 담당자

일상적인 계열사 전략을 대신 승인하지 않습니다. 다음과 같은 그룹 차원의 업무를 담당합니다.

- 계열사별 위험 규모와 성과 비교
- 공통 정책과 지원 기준 관리
- 계열사 간 비용·이해관계 충돌 조정
- 큰 손실, 예산 지원, 브랜드·법규 위험 등 예외 검토
- 승인된 우수 사례의 공유와 확산

### 협력 사용자

물류·마케팅·재무·정산 담당자는 필요한 케이스에만 참여해 실행 가능성, 비용 부담, 정산 결과를 검토합니다.

## 계열사별 문제 맥락

- **현대백화점**: 시즌이 지난 프리미엄 리빙 상품의 장기보관, 공간 대체가치, 브랜드 가격 훼손
- **현대그린푸드**: 냉장·냉동 전력, 유통기한, 식품안전, 폐기와 회수
- **현대홈쇼핑**: 방송 종료 후 잔여재고, 반품률, 정산 지연, 방송 기회비용
- **현대리바트**: 부피가 큰 가구의 보관, 설치·회수, 파손, 예약 취소

## 핵심 업무 흐름

계열사 담당자가 자사 위험재고를 발견하면 계열사별 기준으로 처리 후보를 비교합니다. 후보는 비용, 예상 소진, 잔여재고, 처리기한, 운영 가능성을 함께 검토합니다. 담당자는 일반 전략을 자사 권한으로 승인하고, 실행 결과를 기록합니다.

다음 상황에서만 본사 개입이나 계열사 공동 검토가 발생합니다.

- 그룹 전체 손실에 큰 영향을 주는 대규모 위험재고
- 계열사 간 공동 프로모션이나 비용 분담이 필요한 경우
- 예외 할인, 추가 예산, 브랜드·법규 위험이 있는 경우
- 계열사 간 의견이 합의되지 않는 경우

## 통합의 의미

이 서비스에서 통합은 모든 계열사의 상품과 판단을 하나로 합치는 뜻이 아닙니다.

- 계열사별 업무 공간과 데이터 접근은 분리
- 계열사별 비용·위험·처리기한 기준은 독립
- 위험재고 규모, 처리율, 증분이익 같은 공통 지표만 비교
- 본사는 예외 조정과 우수 사례 공유를 담당
- 계열사 간 번들은 양쪽 계열사가 동의하고 물류·정산 조건이 확인된 경우에만 허용

## 제품 원칙

1. **계열사 책임 우선**: 자사 재고의 일반적인 판단과 실행은 계열사가 담당합니다.
2. **그룹 지원 중심**: 본사는 통제자가 아니라 조정자·지원자·학습 촉진자입니다.
3. **맞춤형 판단**: 계열사별 비용·물류·기한·고객 맥락을 다르게 적용합니다.
4. **공통 언어**: 서로 다른 계열사도 위험노출·처리율·증분이익으로 성과를 비교합니다.
5. **사람의 통제**: AI는 근거와 대안을 제시하고 권한 있는 담당자가 승인합니다.

## 거래 형태 및 소유권 범위

- **직매입 재고 (필수 핵심 대상)**: 백화점/계열사가 소유권, 손익 책임, 처분권을 100% 가진 상품(예: 식품관 등)을 필수 기본 범위로 지정하여 AI 재고 탐지부터 담당자 승인·실행까지의 정합성을 보증합니다.
- **점포 간 재고 이동 (선택/후순위)**: 핵심 처리 대안(할인, 타임세일, 아울렛 이관, 기부, 폐기)을 먼저 검증한 후, 필요시 적용하는 부가적 선택 기능(P2)으로 배치합니다.

## 범위

포함하는 범위는 계열사별 위험재고 탐지, 자사 처리 대안 비교, 비용과 증분이익 시뮬레이션, 계열사별 승인과 실행 결과 회수, 본사 예외 관리, 우수 사례 공유입니다.

1차 계산·실행 검증은 한 계열사에 집중합니다. 특정 계열사를 미리 가정하지 않고, 실제 데이터 품질과 운영·물류 조건을 확인한 뒤 Anchor 계열사를 선정합니다. 다른 계열사는 통합 비교와 확장 대상으로 남깁니다.

제외하는 범위는 통합 쇼핑몰, 통합 장바구니, 소비자 결제, 소비자 주문, 본사의 모든 전략 일괄 승인, 승인 없는 가격 변경, 승인 없는 재고 변경입니다.

## 기대되는 업무 가치

- 계열사가 자사 특성에 맞는 재고 처리 판단을 빠르게 내립니다.
- 본사는 전체 위험을 파악하되 계열사의 운영 책임을 침해하지 않습니다.
- 성공한 처리 전략을 다른 계열사가 참고할 수 있습니다.
- 계열사 간 공동 프로모션은 가능한 경우에만 안전하게 추진됩니다.
