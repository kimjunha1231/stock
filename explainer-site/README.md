# InventoryOS Explainer Site

독립적으로 배포할 수 있는 서비스 설명 사이트입니다. 운영 앱의 실제 화면 캡처와 제품 원칙·PRD·용어 사전을 한 흐름으로 연결합니다.

## 실행

```bash
cd explainer-site
npm install
npm run dev
```

개발 서버는 `http://localhost:3200`에서 실행됩니다.

## 주요 경로

- `/` 랜딩
- `/problem` 문제와 계열사별 맥락
- `/workflow` 작동 흐름
- `/ai-judgment` AI 판단 기준
- `/roles` 사용자 역할
- `/product-tour` 실제 화면 캡처
- `/prd` PRD 요약
- `/glossary` 검색 가능한 용어 사전
